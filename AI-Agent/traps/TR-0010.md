- **vault-sandbox git false positives [11 Sep 2026]:** working-tree `git status`/`git diff` inside `vault-sandbox` lists every `.obsidian/*` file as deleted (` D`), because the sandbox mounts an empty tmpfs over `.obsidian`; Arabic paths also print as octal escapes → use `git -c core.quotepath=false -C /vault status --porcelain -- . ':(exclude).obsidian'` (verified), or compare commits only (`git diff HEAD~1 HEAD`, unaffected).
