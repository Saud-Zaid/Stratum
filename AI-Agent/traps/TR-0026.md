- **An incident:** editing a script with `search_and_replace` returned `files_matched: 0` four times although the text was in the file. The same happened on `AI-Agent/schema/frontmatter.yaml`. The tool touches only Markdown files.
- **The workaround:** the script was written whole with `create_vault_file` after the new text was built in the sandbox and its tests passed.
