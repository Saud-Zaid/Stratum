- `rename_vault_file` updates backlinks across the whole vault automatically (wikilinks, markdown links, embeds, frontmatter aliases) — but it **does not update free text that mentions the old file name outside link syntax** (for example an ordinary sentence in prose) → after any `rename_vault_file`, run `search_vault_simple` for the old name to make sure no orphaned text mentions remain.
