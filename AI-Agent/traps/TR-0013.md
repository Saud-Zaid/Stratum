- **Persist on an already-active tool is a silent no-op [11 Sep 2026, verified]:** `activate_tools(persist: true)` on a tool already session-active returns `already_active` with `persisted: false`, and `activate_tool` returns "already active in the current session", so nothing is written to `data.json` → check the `persisted` field in the result; persist only after the session activation is gone (Obsidian restart), or ask the vault owner to add the tool to the promoted list in Settings → MCP Connector → Tool Loading.
