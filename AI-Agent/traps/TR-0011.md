- **Tool activation is invisible until Claude Desktop restarts [11 Sep 2026, verified]:** `activate_tool(s)` (with or without `persist`) succeeds on the server, yet `tool_search` still finds nothing, because Claude Desktop caches the tool list at startup and ignores `notifications/tools/list_changed`; a new chat does not refetch either → after any activation, ask the vault owner for a full Claude Desktop restart (`pkill -9 -if claude`, then reopen), then `tool_search`; old chats also see the tool afterwards.
