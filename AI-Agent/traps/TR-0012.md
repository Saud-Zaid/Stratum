- **Obsidian restart drops temporary activations [11 Sep 2026, documented by the plugin, not yet observed]:** an `activate_tool` without `persist` lives only in plugin memory, so reloading the plugin or restarting Obsidian removes it while Claude's cached list may still show the tool, making the call fail → use `persist: true` for anything meant to last; if a listed Obsidian tool errors as inactive, check `tool_catalog` before assuming a bug.
