- **An activation lesson, not a design lesson:** a "known traps" mechanism works only if this file is read in the same conversation where the trap is met. The incident above happened in a separate conversation (a weekly tracking one) that never recalled this file, so it was recorded only later after the vault owner narrated it by hand in another conversation. **The lesson:** any conversation that uses the vault's editing tools (not only reading) is expected to check this file the first time it meets unexpected behaviour from a tool, not only long "technical" conversations like this one.
