- **Silent Success with `search_and_replace`:** a real incident — `search_and_replace` returned a success message (`total_replacements: N`) in an earlier conversation, but the edit was **not actually applied** to the file (found by chance later when the file was reviewed for another reason). This is a pattern documented worldwide as "Silent Success" / "returns 200 and is wrong" — the tool's success message is **not enough by itself** as evidence of the real change. **The mandatory rule:** any `search_and_replace` with `dry_run: false` is followed at once — in the same reply, before telling the vault owner "done" — by a `search_vault_simple` call for part of the new text, as an independent check. `dry_run: true` verifies the match **before** execution only; it does not replace the check **after** execution.
