Verified on `AI-Agent/fixtures/addressing-noh1.md` (T05 phase 1, 11 Sep 2026).

- With the default `createTargetIfMissing: true`, appending to a heading that does not exist (`Gamma`) returned "File patched successfully" but created no heading: the content was appended at the end of the file, inside the last existing section.
- With `createTargetIfMissing: false`, the same call on a missing heading (`Delta`) returned `Heading not found: Delta` and changed nothing.
- A typo in a heading name is therefore a silent misplacement unless `createTargetIfMissing: false` is passed.
