# Idea Garden

> **Scope:** a permanent home for every discovery/idea/rarely recurring pattern found in periodic reviews — never deleted, never left in a confusing temporary stop. Each seed either (a) rises to a general rule in [[Second-Brain-User-Guide]] when it recurs in two or more areas, or (b) waits here until it meets another seed that completes it. The monthly review browses this file in full (it does not only search it) looking for two seeds with the same tag that deserve a real MOC linking them.

## How it works
- Each seed: the idea + its source (a link to the area/context) + **one simple thematic tag** (the same general tag rules, see [[Second-Brain-User-Guide]] — no complex dimension system).
- A counter `(review N/5)` at the end of every seed — it grows by 1 at each monthly review of the garden itself that found no recurrence or link for it.
- When the counter reaches 5: the seed moves to the "Dormant seeds" section below — it leaves the active monthly check and is checked only in a longer quarterly review. **It is never deleted.**
- When a tag gathers 3 or more seeds (in either section): the owner is offered the creation of a real MOC that links them with explicit `[[ ]]` links (matching the MOC mechanism already in the guide).
