# Map of content: Templates

An index of the core Templater templates at the root of `Templates/` — the single pattern for creating every kind of file in the Second Brain, with [[Second-Brain-User-Guide]] as its reference.

## Overview

| Template | Purpose |
|---|---|
| [[Area]] | an ongoing area of responsibility with no set end (PARA) |
| [[Project]] | a project with a clear goal and end (PARA) |
| [[Resource]] | a fixed knowledge reference independent of any Area/Project |
| [[Person]] | a person's file in the relationship network |
| [[Permanent]] | a permanent note (Zettelkasten) |
| [[Fleeting]] | a first, passing note before promotion to Permanent |
| [[Literature]] | a reading / external-source note |
| [[MOC]] | a map of content for a main topic — this very file comes from this template |
| [[Weekly-Tracker]] | weekly tracking of tasks and achievements (the `Current-Week.md` pattern) |
| [[Changelog]] | a separate changelog for a given area when there is a real need |
| [[Experiment]] | trying a tool or an algorithm: the goal, what was done, and the results |
| [[Task-Spec]] | a specification for a large task with numbered steps and a progress log (the `task-spec` skill) |
